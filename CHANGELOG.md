# 1.7.1

- Added optional `tracking.reverse_injection` to choose injection direction when exporting.
- Normal mode: animation user → doll owner. Reverse mode: doll owner → animation user.
- Reversal affects liquid/mess only. Owner slowdown, forced defeat and temporary struggle protection remain unchanged. Reverse mob use skips liquid/mess but retains owner control effects.
- Included updated example settings and English/Chinese instructions.

- 新增 `tracking.reverse_injection`，制作者可自行选择注入方向。
- 默认：动画使用者 → 娃娃主人；反向：娃娃主人 → 动画使用者。
- 反向仅改变液体/mess 注入；主人的减速、战败及禁止挣扎保持不变。怪物作为使用者时仅跳过液体/mess，保留主人的控制效果。
- 同步更新示例配置和中英文说明。
